# 플래시카드 답변 전수 점검 체크리스트

366장을 카드 하나씩 점검한다. 체크는 사용자가 확인을 마쳤을 때 표시한다.

## 카드당 점검 항목

1. 사실 정확성. 틀린 내용, 오래된 정보, 부정확한 단정을 근거와 함께 교정
2. 두괄식. 첫 문장만 외워도 답이 되는지
3. 분량. 면접에서 1분 내로 말할 수 있는지, 중복 문단이 없는지
4. 어투. gn-voice 규칙 준수 여부 (`.claude/rules/flashcard-conventions.md` 참고)
   - 정의를 묻는 카드는 두괄식 산문, 나열을 묻는 카드는 한 줄 한 항목
   - 같은 길이의 완결 문장을 연달아 쓰지 않기. 문장 길이에 낙차를 줄 것
5. 약어 표기. 개념의 주인 카드라면 `JIT(Just-In-Time)` 형태로 풀어쓰기

## 진행 규칙

- 카드 하나 점검이 끝나면 커밋 메시지를 제안하고 사용자 승인을 받은 뒤 커밋. 승인 없이 커밋 금지
- 커밋 메시지에 수정한 카드 id 명시
- 수정 불필요 카드는 판정 사유 한 줄만 대화에 남기고 넘어감
- 대화에 공부 포인트나 부연 해설을 덧붙이지 않음. 점검 결과와 수정 내용만 보고
- 배치마다 `pnpm exec prettier --check src/data/<파일>.ts` 통과 확인
- 브랜치는 `chore/refine-flashcards`, PR은 사용자가 직접 생성
