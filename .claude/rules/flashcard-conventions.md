# 어투 기준: gn-voice

질문과 답변의 어투는 [gn-voice](https://github.com/gongnyang/gn-voice) 규칙을 따른다. 전역 스킬로 설치되어 있으며 원문은 `~/.claude/skills/gn-voice/references/voice-core.md`.

플래시카드는 저자 개인 에세이가 아니라 학습용 설명문이므로 **표면 규칙만 적용**한다. gn-voice §3(장르 밖) 원칙에 따라 §1의 3·5·6·11·15와 §4 Do-NOT을 적용하고, 리듬·인격·화계 낙차(§1의 8~10·13·14)와 음슴체·은어·자기비하·사담·미완결 종결은 적용하지 않는다.

# 플래시카드 질문 컨벤션

- question 필드는 구어체 한국어로 작성
- 끝맺음: ~나요?, ~가요?, ~뭔가요? 등 자연스러운 의문형
- **명사형 종결 금지.** gn-voice §3이 개조식 명사종결을 AI 노트 티로 규정한다
- 물음표 2개 이상 복합 질문 금지, 한 카드는 하나만 묻는다
- 독자 호명 금지 (여러분, 독자님)
- ✓ "타입 추론이란 뭔가요?"
- ✓ "호이스팅이 뭔가요?"
- ✗ "타입 추론이란?"
- ✗ "SPA의 단점은?"
- ✗ "타입 호환성(Type Compatibility)과 구조적 타이핑이란?"

# 플래시카드 답변 안티패턴

답변이 AI가 쓴 것처럼 느껴지게 만드는 패턴 목록. 아래 표현은 피하세요.

- `~을 통해 달성할 수 있습니다` → `~하면 됩니다`
- `첫째, 둘째, 셋째` 나열 구조 → 자연스러운 산문으로 연결
- `결론적으로`, `요약하자면`, `정리하면`, `핵심은` → 생략하거나 바로 결론을 말할 것
- `~라고 볼 수 있습니다` → `~입니다`로 단정
- `~할 수 있습니다` 반복 남발 → 한 번만 쓰거나 단정형으로
- 모든 문장이 비슷한 길이 → 짧은 문장과 긴 문장을 섞어 리듬 변화를 줄 것
- **줄표 `—`·`–` 금지.** gn-voice 실측 3.3%에 불과한 AI·번역투 신호이며, 연결은 쉼표·가운뎃점·문장 분리로 처리
- 이모지·초성체(ㅋㅋ/^^) 금지
- 마무리에 재요약·교훈·CTA를 붙여 봉합하지 말 것
- 수치·고유명사는 뭉개지 말고 그대로 쓸 것
